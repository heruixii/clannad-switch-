**适用游戏：Nintendo Switch《CLANNAD》v1.0.7** · Title ID：`0100A3A00CC7E000` · 移植汉化：**ALTIRKIE**。

## 唯一推荐安装包

[**fix10 完整汉化 ZIP（单包直接安装）**](https://github.com/heruixii/clannad-switch-/releases/download/v1.0.7-fix10/CLANNAD_CHS_v1.0.7_fix10_FULL_20261014.zip)

文件名：`CLANNAD_CHS_v1.0.7_fix10_FULL_20261014.zip`，485,507,985 字节，SHA-256：`E8CC4767AB446CA2C9D550F3B1EECE91ACCF872549BF516EC69A6C43C04E4732`。

完整包已整合全部 7 个 RomFS PAK（`SCRIPT`、`FONT`、`MANUAL`、`OTHCG`、`PARTS`、`PARTS2`、`SYSCG`）和 **唯一一个**匹配本游戏 Build ID 的 ExeFS IPS。不需要先装旧版本。

## A. 新用户直接安装

1. 关闭游戏，确认版本为 **v1.0.7**，建议备份存档。
2. 解压 ZIP（不要改动其中相对路径），将 `atmosphere` 文件夹复制到 SD 根目录并合并。
3. 确认 `atmosphere/contents/0100A3A00CC7E000/romfs/` 有七个 PAK。
4. 确认 `atmosphere/exefs_patches/CLANNAD_CHS_v1.0.7_fix9/` 只有一个 IPS，并且没有其它本游戏的活动 IPS。
5. 重启 CLANNAD，正常读取存档，检查中文剧情、菜单、设置、姓名和团子百科。

## B. 已安装任何历史汉化：先卸载旧包，再安装完整包

**先做备份：** 彻底关闭游戏，备份旧 RomFS、ExeFS、存档。对用户自装的其他 Mod，请保留，不要直接删除整个 `atmosphere`。

1. SD 卡 `atmosphere/exefs_patches/` 下，移出所有旧的 `CLANNAD_CHS_*` 补丁文件夹（旧 fix3～fix9）。需要时先复制到电脑，**不动其它游戏对应的目录**。
2. SD 卡 `atmosphere/contents/0100A3A00CC7E000/romfs/` 下，将旧汉化七个 PAK 移走，历史调试 `.disabled` 文件在确保电脑已备份后也可以移走。**仅移除汉化覆盖文件，不动存档，也不删游戏本体**。
3. 解压最新 fix10 完整 ZIP，将 `atmosphere` 放到 SD 卡根目录合并，确保所有七个 PAK 和一个 IPS 已恢复。
4. 重启游戏，读旧存档测试。**不需要重新开档。**

## C. 想完全恢复未汉化的游戏

退出游戏后，将**仅属于 CLANNAD 汉化**的 `CLANNAD_CHS_*` ExeFS IPS 与 `atmosphere/contents/0100A3A00CC7E000/romfs/` 下本汉化的七个 PAK 移除或移到电脑。保留原游戏、本体更新、存档和其它 Mod。Atmosphère 将使用未覆盖的原版资源。

## E. 常见问题

- **无中文/菜单漏翻译：** 检查七个 PAK 是否都在，不是误装旧的 fix10 升级包或只复制了部分文件。
- **中英文重叠、名字仍英文：** 检查 ExeFS 是否只有一个 IPS，并确认游戏版本是 v1.0.7。
- **剧情闪退：** 检查 `SCRIPT.PAK` SHA-256 是否为 `DC2AD2D10654226C8013E46C07B8C9D44BC5CEC147500AB684AD66C26016D5AD`；附上 Atmosphère 报错日志和存档剧情日期。
- **同目录还有别的 Mod：** 不要整目录删除，只移走本汉化对应的文件。
