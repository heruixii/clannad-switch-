# CLANNAD Nintendo Switch fix10：旧补丁卸载、升级安装与问题检查

**适用游戏：CLANNAD v1.0.7** · Title ID `0100A3A00CC7E000` · **Switch 移植汉化：ALTIRKIE**

## 升级前：备份，不要清除存档

请先完全关闭游戏，通过 DBI/MTP、读卡器等方式访问 SD 卡。建议把旧 `atmosphere/exefs_patches/CLANNAD_CHS_*` 和 `atmosphere/contents/0100A3A00CC7E000/romfs` 中的已修改文件复制到电脑做备份。不要删除游戏本体及用户存档。

`fix10` 包本身包含三个文件：

```
atmosphere/
├─ contents/
│  └─ 0100A3A00CC7E000/
│     └─ romfs/
│        ├─ SCRIPT.PAK       # 修复全部已识别的过期跳转目标
│        └─ FONT.PAK         # 已验证中文字体
└─ exefs_patches/
   └─ CLANNAD_CHS_v1.0.7_fix9/
      └─ CF38595316BAA425E792CE5CD122DFC600000000000000000000000000000000.ips
```

**这不是完整首次安装包。** 原先完整汉化的五个额外资源 **必须保留**：`MANUAL.PAK`、`OTHCG.PAK`、`PARTS.PAK`、`PARTS2.PAK`、`SYSCG.PAK`。

## 从 fix3～fix9 升级

1. 在 `atmosphere/exefs_patches/` 中，把所有旧的 `CLANNAD_CHS_*` 文件夹**备份至本目录以外**，然后从 `exefs_patches` 中移走。这一步也包括 fix9 旧目录：安装本包会重新创建唯一正确的 fix9 IPS。勿与历史版本并存。
2. 备份 `atmosphere/contents/0100A3A00CC7E000/romfs/SCRIPT.PAK` 与 `FONT.PAK`。
3. **不要删除整个 romfs 文件夹**，保留另外五个 PAK。
4. 解压 fix10 的 ZIP，复制其中 `atmosphere` 文件夹到 SD 卡根目录。允许覆盖 `SCRIPT.PAK` 和 `FONT.PAK`。
5. 检查 `romfs` 内七个正常命名的 PAK 已存在，`exefs_patches` 只有一个匹配本游戏 Build ID 的 `.ips`。
6. 完全退出并重新启动游戏，读原存档检查剧情、中文、菜单、设置及主角姓名。

首次安装则应先安装 [fix8 全量基础包](https://github.com/heruixii/clannad-switch-/releases/tag/v1.0.7-fix8)，再按上述步骤升级 fix10。

## 需要清理旧诊断版本吗？

早期本机调试可能留下 `SCRIPT.PAK.original_disabled`、`SCRIPT.PAK.ascii_disabled`、`SCRIPT.PAK.scene0414_disabled` 等不被游戏加载的诊断备份。**确认电脑已有副本且 fix10 安装稳定后**，可以移出 SD 卡 `romfs` 到电脑归档以节省空间，避免直接覆盖或把备份意外改回有效 `.PAK`。这不是升级必需步骤。

## 完全卸载汉化

1. 备份游戏和 Mod 文件，完全退出游戏。
2. 从 `atmosphere/exefs_patches/` 中移走仅属于 CLANNAD 的汉化 `CLANNAD_CHS_*` 文件夹；不要误删其它游戏补丁。
3. 只清理 `atmosphere/contents/0100A3A00CC7E000/romfs/` 内由该汉化安装的七个 PAK；如果同目录有自己的其他 Mod，请逐项识别，不要直接删除整棵 contents 目录。
4. 重启游戏，恢复未覆盖的原版资源。**无需删除游戏本体、游戏更新或游戏存档。**

## 出现问题时先回退一个变量

- 若恢复 ExeFS 后菜单/姓名异常：仅将 `.../CLANNAD_CHS_v1.0.7_fix9/*.ips` 改名追加 `.disabled`，保留 SCRIPT 和 FONT，确认脚本是否继续稳定。
- 若新 SCRIPT 与旧存档产生错误：先确认是本包 SHA 对应的 `SCRIPT.PAK`，并核对游戏 v1.0.7；仍有异常时保存崩溃日志和此前备份。不要用旧脚本与新版配置混合直接判定根因。
- 若出现缺字：确认本包 `FONT.PAK` 有效、无另一个 Mod 覆盖同名路径，且哈希一致。
- 若未汉化菜单/团子百科：通常是首次安装只装了 fix10、缺少原完整 fix8 的五个 UI/资源 PAK。
- 若仍闪退：保存 `atmosphere/fatal_errors` 或 `atmosphere/crash_reports` 下相关错误报告（实际目录因系统配置不同而异），尽量提供日期、截图和前后的剧情文字。
