# CLANNAD Switch 汉化工程目录与复现说明

## 当前目录结构

- `01_container`：原始容器与解包阶段资料。
- `02_romfs`：Switch RomFS 基础资源。
- `03_text`：PC/Switch 文本抽取、对齐、回写及 UI 工作资料。
- `04_scripts`：保留的构建、转换、QA 与最终发布脚本。
- `05_build`：最终 fix8 的可复现构建依赖与 QA 产物。
- `06_release`：当前唯一正式发布版本。
- `07_archive`：旧版发行包、探针截图/OCR 与探索性分析脚本归档。
- `docs`：工程文档、贡献说明、使用说明。
- `tools`：项目使用的辅助工具。

## 最终 fix8 依赖

不要仅因为目录名带旧 fix 编号就删除。fix8 是逐步收敛形成的，最终发布脚本仍依赖以下稳定产物：

- `SCRIPT.PAK` → `05_build/script_package_fix7/SCRIPT.PAK.out`
- `FONT.PAK` → `05_build/font_package_fix2/FONT.PAK.out`
- `SYSCG.PAK` → `05_build/ui_packages_v1/SYSCG.PAK.out`
- `PARTS.PAK` → `05_build/ui_packages_fix5/PARTS.PAK.out`
- `PARTS2.PAK` → `05_build/parts2_fix4/PARTS2.PAK.out`
- `MANUAL.PAK` → `05_build/ui_packages_v1/MANUAL.PAK.out`
- `OTHCG.PAK` → `05_build/OTHCG.PAK.out`
- ExeFS IPS → `05_build/fix8_exefs/CF38595316BAA425E792CE5CD122DFC6.ips`

QA 仍引用：

- `05_build/config_fix4`
- `05_build/button_fix5`
- `05_build/keyword_fix6`
- `05_build/fix6_exefs`
- `05_build/fix7_name_qa.json`
- `05_build/fix8_exefs`
- `05_build/font_package_fix2`
- `05_build/title_fix3_ocr_qa.json`

因此在彻底重构脚本路径前，不要移动上述依赖目录。

1. `04_scripts/verify_release_sources_fix8_v21.py`

最终 SCRIPT 包包含 213 个 Switch `SEEN` 场景，并基于 PC 日中对齐结果完成正文与选项移植。范围包含本篇、各路线以及 After Story（后日谈）。Switch 独有团子百科由 `_KEYWORD` 表单独完成汉化。

## 安全边界

- 不把用户私有密钥复制进工程或发布包。
- 不把旧 release 当作当前版本重新分发。
- 不随意删除带旧 fix 编号但仍被最终脚本引用的依赖。
- 发布前始终重新执行最终 ZIP QA。
