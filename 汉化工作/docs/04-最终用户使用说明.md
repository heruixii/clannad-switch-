# CLANNAD Nintendo Switch 简体中文补丁 fix8 使用说明

## 1. 适用版本

- 游戏：Nintendo Switch《CLANNAD》
- 游戏版本：**v1.0.7**
- Title ID：`0100A3A00CC7E000`
- 补丁版本：**fix8**
- 加载方式：Atmosphère LayeredFS + ExeFS IPS

本补丁按 v1.0.7 的 RomFS 与程序 Module ID 制作。其它游戏版本不保证兼容。

## 2. 汉化内容

fix8 已覆盖：

- 本篇剧情；
- 各角色路线；
- **After Story（后日谈）完整剧情文本**；
- 剧情选项；
- 标题菜单及主要系统 UI；
- 设置界面；
- Save / Load / 返回 / 下一项等系统按钮及提示；
- 团子百科 71 条词条、标题、正文与底部字母目录；
- 主角“朋也”姓名显示、默认名与姓名设置逻辑；
- 游戏内手册；
- 中文字库与相关 UI 图像。

Logo、商标及控制器 A/B/X/Y/L/R 等按键符号可能保持原样，这些不属于漏汉化。

## 3. 安装前准备

建议先确认：

1. 游戏已经更新到 **v1.0.7**；
2. 能正常通过 Atmosphère 启动游戏；
3. SD 卡有足够空间；
4. 已经删除或移走旧版 CLANNAD 汉化补丁，尤其是旧的 ExeFS IPS。

## 4. 安装方法

1. 解压 fix8 发布包。
2. 得到一个 `atmosphere` 文件夹。
3. 将该 `atmosphere` 文件夹复制到 SD 卡根目录并合并。
4. 重新通过 Atmosphère 启动游戏。

最终结构中应存在：

`atmosphere/contents/0100A3A00CC7E000/romfs/`

其中包含：

- `SCRIPT.PAK`
- `FONT.PAK`
- `SYSCG.PAK`
- `PARTS.PAK`
- `PARTS2.PAK`
- `MANUAL.PAK`
- `OTHCG.PAK`

同时应存在：

`atmosphere/exefs_patches/CLANNAD_CHS_v1.0.7_fix8/`

其中只有当前 fix8 对应的 IPS。

## 5. 从旧版本升级

如果此前装过 fix1～fix7：

1. 删除或移走旧的：
   `atmosphere/contents/0100A3A00CC7E000/romfs/`
2. 删除旧的 CLANNAD 专用：
   `atmosphere/exefs_patches/CLANNAD_CHS_*`
3. 再复制 fix8 的 `atmosphere` 到 SD 卡根目录。

**不要同时加载两个不同版本的 CLANNAD IPS。**

## 6. 存档兼容

fix8 没有要求重新开档。

姓名问题已经在运行时姓名读取路径中修复，因此旧存档也应直接读取中文/日文姓名槽，不再依赖重新开始游戏。

正常情况下可以继续使用已有存档。

## 7. 建议实机检查

安装完成后建议检查：

- 标题菜单是否显示中文；
- 设置页是否没有中英文双层重叠；
- Yes / No / Back / Next 等按钮是否只显示一份中文；
- 快进、回退、跳转等按钮是否正常；
- 主角姓名是否显示“朋也”；
- 团子百科底部是否显示清晰的 A/B/C…字母目录；
- 团子百科条目标题与正文是否为中文；
- 进入 **After Story（后日谈）** 后剧情正文是否继续正常显示中文。

## 8. 常见问题

### 补丁完全没有生效

优先检查：

- 游戏是否确实为 v1.0.7；
- Title ID 是否为 `0100A3A00CC7E000`；
- 文件夹是否多套了一层目录；
- 是否通过 Atmosphère 启动；
- 是否仍存在旧 CLANNAD IPS 冲突。

### 菜单中文但某些运行时 UI 异常

这通常意味着 RomFS 已加载，但 ExeFS IPS 未正确加载。检查 `atmosphere/exefs_patches/CLANNAD_CHS_v1.0.7_fix8/` 是否存在，并确保没有同时保留旧版 CLANNAD IPS。

### 主角仍显示英文名

fix8 已修复最终运行时姓名槽选择。若仍出现该现象，首先确认实际加载的是 fix8 IPS，而不是旧 fix7 或更早版本。

### 团子百科目录挤在一起

这是 fix5 的旧问题；fix8 已恢复原版内部英文字母排序键。若仍出现，通常说明 `SCRIPT.PAK` 没有被 fix8 版本正确替换。

## 9. 卸载

删除本补丁加入的 CLANNAD RomFS 覆盖目录和 CLANNAD fix8 ExeFS patch 目录即可恢复原版资源加载。

操作前如有自行添加的其它 CLANNAD 模组，请先备份并区分文件来源。
